# Security policy

GoForge is under active pre-1.0 development. Security fixes are applied to the
current `main` branch; older development snapshots are not supported.

Please do not open a public issue for a suspected vulnerability. Report it
privately through [GitHub security advisories](https://github.com/ShanilKoshitha/goforge/security/advisories/new) with a concise reproduction, affected
version or commit, and the impact you observed. You can expect an initial
acknowledgement within seven days.

Never include production credentials, personal data, or access tokens in a
report or reproduction.
